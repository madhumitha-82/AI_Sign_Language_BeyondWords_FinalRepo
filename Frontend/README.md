# 🤟 BeyondWords

**BeyondWords** is an AI-powered sign language learning platform designed to make learning engaging, interactive, and accessible. It combines adaptive learning, gamification, and communication tools to bridge the gap between Deaf and hearing communities.

---

## 🌟 Features

### 🤖 AI-Powered Learning

* Personalized learning paths based on user progress.
* Interactive lessons with instant feedback.

### 🎮 Gamification

* Earn XP by completing lessons.
* Maintain daily learning streaks.
* Unlock achievements and badges.
* Compete on global leaderboards.

### 🌐 Multi-Language Support

* American Sign Language (ASL)
* Indian Sign Language (ISL)

### 🎙️ Communication Tools

* Speech-to-Text (STT)
* Text-to-Speech (TTS)

These features help enable smoother communication between Deaf and hearing individuals.

### 📊 Admin Dashboard

* Manage lessons and courses.
* Track learner progress.
* View platform analytics.
* Easily scale the platform with additional sign languages.

## 🚀 Getting Started

### Prerequisites

* Node.js (v18 or later)
* npm

### Installation

Clone the repository

```bash
git clone https://github.com/<your-username>/BeyondWords.git
```

Move into the project directory

```bash
cd BeyondWords
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

## 🎯 Problem Statement

Learning sign language is often difficult due to limited resources, lack of interaction, and minimal support for multiple sign languages. Existing platforms generally provide static content with little feedback or motivation.

---

## 💡 Our Solution

BeyondWords transforms sign language learning into an engaging experience using AI and gamification. By supporting both ASL and ISL while integrating Speech-to-Text and Text-to-Speech, the platform makes communication and learning more inclusive and accessible.
